# 🃏 Blackjack

A 2D Blackjack game built from scratch using **Python and Tkinter**.

I started this project while learning Python as a way to apply programming concepts beyond individual exercises. The game includes Blackjack game logic, betting, card rendering, GUI state management, and automated testing.

## Features

- Standard Blackjack gameplay
- HIT and STAND mechanics
- Dealer behaviour and card reveal
- Blackjack and bust detection
- Chip-based betting and bankroll system
- 3:2 Blackjack payouts
- 2D interface built with Tkinter Canvas
- Automated tests for core game and betting logic
- Controlled test scenarios for difficult-to-reproduce game states

## Built With

- Python
